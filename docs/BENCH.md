## Test-file contract for baselines

- Plain pytest files named `test_*.py` or `*_test.py` (functions `test_*` using `assert`).
- Import the function under test with `from solution import prorate_refund`. The loader writes the mutant's full module source to `solution.py` in a temp dir and runs `python -m pytest` there; no other imports of repo code are available.
- PR's own tests: `demo_target/prorate_refund/ai_pr/`. LLM blind tests: `bench/llm_artifacts/` (all files in the directory are run together; a mutant is caught if any test fails, a pytest timeout counts as failure, a collection error does not count as caught).
- Tests should pass on the correct reference; the run reports whether they do.
